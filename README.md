# EcoTech - Plataforma de Hardware Eficiente

Proyecto final desarrollado para el curso de React en CoderHouse. Una plataforma webapp de e-commerce enfocada en soluciones biotecnológicas, automatización y hardware eficiente, integrada con Firebase para la persistencia de datos.

## Características Principales

*   **Catálogo Dinámico:** Renderizado de productos desde Firestore filtrados por categorías.
*   **Detalle de Producto:** Vista especializada con control de stock integrado.
*   **Carrito Global:** Gestión de estado de compras en tiempo real utilizando React Context.
*   **Checkout & Tracking:** Formulario de validación que genera y registra la orden en la nube, devolviendo un código único de seguimiento al usuario.

## Tecnologías Utilizadas

*   **Frontend:** React, React Router Dom, Bootstrap / CSS Standard
*   **Backend & DB:** Firebase (Cloud Firestore)
*   **Herramienta de Construcción:** Vite
